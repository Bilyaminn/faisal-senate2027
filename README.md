# Dr. Faisal Shuaib Campaign Frontend

A lightweight, responsive campaign landing page and browser-only poster studio built with semantic HTML, modern CSS and native ES modules, with Vite as the development/build tool.

## Run locally

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
npm run preview
```

## Highlights

- Responsive editorial campaign landing page
- APC branding and supplied campaign imagery
- Mobile navigation
- SEO/social metadata
- Optimized WebP assets with JPG fallbacks
- Two poster templates: Classic and Modern
- Client-side image processing; supporter photos are not uploaded
- Live preview before supporter photo upload
- PNG download and Web Share support where available
- Accessible controls and reduced-motion support
